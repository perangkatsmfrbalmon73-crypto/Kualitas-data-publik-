Metode, Batasan, dan Rekomendasi

Dirancang agar hasil dapat ditelusuri, direplikasi, dan tidak menyamarkan asumsi.

Metode DQ-7

  1. Unit analisis: portal, dataset, metadata, distribusi berkas, dan endpoint API publik.
  2. Dimensi: ketersediaan, keterbukaan, metadata, kemutakhiran, interoperabilitas, aksesibilitas, dan keandalan.
  3. Normalisasi: indikator dikonversi ke skala 0–100; nilai kosong tidak otomatis dianggap nol.
  4. Agregasi: rata-rata tertimbang dengan bobot yang ditampilkan secara terbuka.
  5. Validasi: benchmark eksternal dibandingkan dengan audit sampel dan pengukuran API langsung.
  6. Ketidakpastian: simulasi, estimasi, dan benchmark selalu diberi label berbeda.
