Metodologi, Batasan, dan Solusi

Struktur untuk memastikan hasil dapat ditelusuri dan tidak menyamarkan asumsi.

Metode DQ-7

  1. Unit analisis: portal, dataset, metadata, distribusi berkas, dan endpoint API publik.
  2. Dimensi: ketersediaan, keterbukaan, metadata, kemutakhiran, interoperabilitas, aksesibilitas, dan keandalan.
  3. Normalisasi: seluruh indikator dikonversi ke skala 0–100; nilai kosong tidak otomatis dianggap nol.
  4. Agregasi: rata-rata tertimbang. Bobot dan skor ditampilkan agar dapat direplikasi.
  5. Validasi: benchmark eksternal dibandingkan dengan audit sampel dan pengukuran API langsung.
  6. Ketidakpastian: indikator simulasi diberi label dan tidak dipresentasikan sebagai statistik resmi.
